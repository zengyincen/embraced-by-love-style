# 篇章形态与结构选择

只选择最贴近任务的一种形态。模板是骨架，不是必须显露的公式。

## 1. 微诗或短句

适用于 2—8 行诗、图片配文、标题式表达。

结构：

`平静自我/具体物象 → 对方或外界出现 → 一个出人意料但可理解的变化`

要求：

- 只用一个核心隐喻；
- 让动词承担力量，如“落、亲吻、抽芽、哗然”；
- 不在末行解释寓意；
- 陌生词必须语义清晰，不能只求朦胧。

## 2. 回忆叙事散文

适用于老师、朋友、家人、童年、遗憾与重逢。

结构：

1. 从今日街道、天气、声音或物件切入；
2. 由同一物件折回过去；
3. 选择一至两个关键事件，不做流水账；
4. 写当年的误解与身体反应；
5. 回到今日，得到迟来的理解；
6. 用开头物件完成回环，让感谢、歉意或祝愿保留一点未说尽。

推荐比例：场景与事件约六成，内省约三成，收束约一成。

## 3. 书信、赠别与关系叙事

适用于“给某人”“送”“别”、生日或毕业赠言。

结构：

`此刻正在发生的离别 → 关系中最小但最亮的细节 → 一次裂缝或遗憾 → 承认距离与变化 → 给出不占有的祝愿`

保持称谓与代词一致。少列愿望清单，多写一个真正代表关系的动作。允许“我爱你”“对不起”难以开口，但不能永远用修辞逃避意思。

## 4. 年终回望与成长随笔

适用于年度总结、生日节点、阶段性复盘。

结构：

1. 用一个贯穿物象定调，如灯、土地或列车；
2. 按三至四个主题组织经历，不逐月罗列；
3. 每一部分放入一件具体事件和一个认识变化；
4. 承认疲惫、错误或未完成，不制造完美成长线；
5. 回扣主物象，把未来写成可执行的方向。

小标题可用同句式复沓，但每节必须提供不同事实。

## 5. 公共主题与新年献词

适用于年度公共事件、青年责任、集体鼓励。

结构：

`共同时间坐标 → 少量具体人物/事件 → 提炼共享价值 → 诚实写出困难 → 号召继续行动`

每个公共事实须可靠。案例不求多，求能支撑价值。宏大叙述中穿插一个普通人的动作，避免全篇都是口号。

## 6. 文学与文化随笔

适用于地域文学、作品中的雪、跨文化阅读等主题。

结构：

1. 提出一个真正需要回答的问题；
2. 选取二至四个最相关文本或地域，不铺满世界文学清单；
3. 每个例子写出具体文本细节和个人阅读经验；
4. 比较共振与差异，而非只做华丽定义；
5. 回到自身处境，给出暂时性答案。

文学引文、作者、情节和历史背景应核实。不要为气势制造不存在的史实或人物经历。

## 7. 自我宣言与议论散文

适用于与旧习作别、确立写作观或人生观。

结构：

`旧判断 → 一件现实经历动摇它 → 重新辨认自己 → 给出新原则 → 说明将如何实践`

避免在后半篇用五种说法重复同一宣言。原则必须对应动作，例如去劳动、记录现场、核对事实、主动表达或完成道歉。

## 8. 梦境式寓言

适用于树屋、风、海豚、门等象征性叙事。

先建立清晰的空间规则，再允许象征扩张。控制角色数量，保持问答逻辑。若“风”既代表时机又代表勇气，全文不要突然让它承担爱情、命运、社会评价等所有含义。结尾可揭示象征，但不要逐项解释。
