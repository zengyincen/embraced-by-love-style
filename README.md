# Embraced by Love Style

> [!IMPORTANT]
> **这是一个个人自用项目。** 它只为作者本人保存、调用和持续校准个人文风；仓库与 npm 包公开，仅用于个人版本管理、跨设备安装和迭代，不以通用写作模板为目标。

一个从作者个人作品中持续蒸馏、仅供作者本人迭代的中文文风 Skill，适用于 Codex 中的散文、随笔、书信、短诗、小说、成长叙事、文化历史书写、地方抒情、人物与离散记忆、古典诗词鉴赏、近代文言化历史叙事、续写、润色与审稿。

它追求私人化的感知和意识流式联想：把散落、矛盾的情感汇聚到笔尖，再顺着当下的记忆与呼吸，流畅地“挤”成文字。

它不是标志句式、固定意象或篇章模板的集合，也不靠机械拆散排比、删除金句、缩短解释来制造所谓“人味”。整齐、浓烈、繁复都可以保留，只要它们从当前语境自然长出，仍属于这个具体的人。

近代文言化语域以半文半白为骨架：让尺牍礼法、家族记忆、个人见闻和公共历史互相嵌合，以古典句法容纳现代名物，并严格区分亲见、转述、推断与未知。

## 多源文学谱系

这次升级没有把许多作家混成一个笼统的“文学腔”，而是在私人意识流底盘之上增加五条按需调用的引擎：

| 引擎 | 主要解决的问题 |
|---|---|
| 文化历史与行走 | 遗址、人物、史料、山河与今日之我的关系 |
| 感官、地方与物哀 | 声音、气候、器物、乡土、旅行与哲思转身 |
| 人物、城市与离散记忆 | 家族、旧友、城市盛衰、迁徙与记忆版本 |
| 古典诗学与细读 | 字词、声律、结构、诗学概念与生命兴发 |
| 诗性压缩、小说反讽与复调 | 现代诗、有限视角、荒诞、冷讽与多声部叙事 |

每次创作只选一条主引擎，必要时增加一条辅引擎。余秋雨、川端康成、余光中、刘亮程、王国维、白先勇、鲁迅、史铁生等阅读谱系只提供可泛化的方法，不形成“仿某位作家”的开关；Skill 不复制其标志句式、独特比喻、惯用意象或具体作品结构。

## 代表作品（节选）

以下文字均为作者本人作品节选，只用于说明与校准这个自用 Skill 的文风来源。

### 《动心》

> 我这样死板的山 也会为你哗然

### 《又是这个路口，中山路的樟树又抽出新芽》

> 蝉鸣在树冠深处织成金线，将记忆缝进每片摇动的叶影里。
>
> 十字路口的红绿灯换了三次颜色，我仍站在原地数那些飘落的花。原来有些道别不需要挥手，就像当年严厉的批评，温热的期望不需要只言片语。

### 《十年后，我扇出的一巴掌重重地落在了我脸上》

> 也许，十年前，我对他被欺凌时的沉默，像是我在加害他时扇出的一巴掌，而十年后，我们的擦肩而过，是那一巴掌重重的回落在我的脸上。

### 《落在我心头的雪》

> 南方的雪终究是吝啬的，它不肯在地面多做停留，却把最珍贵的部分藏进记忆的冰晶。

### 《写一盏灯，把故事照亮》

> 这一年，我把根扎进了土地里。
>
> 我选择了走向乡村和土地，走向那片被无数人离开却仍等待耕耘的乡土。

### 《我决意同过往的沉疴与无谓的矫情作别》

> 原来，好的文字从不是“矫”出来的，而是“走”出来的——走过迷茫无措的困顿，走过自以为是的浮躁，走到愿意坦然承认自己也曾软弱、也曾矫情，也曾在一段文字里，笨拙地寻找与世界对话的出口。

### 《祖父大人钧鉴》（近代文言化家书节选）

> 狮城一别，岁星已过一周。垂髫少年，今已壮矣，唯父祖之容颜依稀，常在梦中，前接家书知一门安好，甚慰。
>
> 中共为之为政如何，孙非局中人，不能知其究竟，但亲见数事，可以为大人言。

## 安装或更新

```bash
npx embraced-by-love-style@latest
```

再次执行同一命令即可更新。更新前，安装器会把原目录完整备份到：

```text
~/.codex/skills/.embraced-by-love-style-backups/
```

预览操作或指定其他 Codex skills 目录：

```bash
npx embraced-by-love-style@latest --dry-run
npx embraced-by-love-style@latest --target /path/to/skills
```

## 使用

```text
$embraced-by-love-style 根据这些真实素材，写一篇中度文风的成长散文。
```

```text
$embraced-by-love-style 保留事实和我的口吻，让情绪自然流动；只修突兀和失真，不要机械拆掉排比、金句或解释。
```

```text
$embraced-by-love-style 把这些史料写成一封近代文言化家书，半文半白，区分亲见、转述与推断。
```

```text
$embraced-by-love-style 从这处旧城遗址和我提供的史料出发，写一篇文化行旅散文；保留私人疑问，不替历史下过大的结论。
```

```text
$embraced-by-love-style 细读这首诗，从“归”字的声律和位置展开，再联系我的这段经历；区分文本解释与个人感发。
```

默认采用中度文风。可以明确要求轻度、中度或高度浓度。

### 文风原则

Skill 学习的是情感怎样聚拢、记忆怎样互相触发、念头怎样推着下一句话出现，不复制作者旧作的固定开头、复沓句、转折句、结尾句或高频意象。新的作品应当像同一个人在新的处境里继续表达，而不是旧作换了一组名词。

当用户点名某位作家时，Skill 只吸收可泛化的高层特征，例如古典与现代交叠、感官密度、句势伸缩、叙述距离、复调以及私人经验向哲思转身；不复制特定作家的独特比喻、标志句式、惯用意象或作品结构。

### 素材规则

Skill 只采用当前提示词中明确提供的素材，不会主动扫描当前工作区寻找“真实经历”。提示词有真实素材时据此写作；没有素材时直接原创，不追问、不放占位符，也不会把虚构内容声称为作者亲历。

Skill 源文件位于 `skill/embraced-by-love-style/`。修改后依次运行：

```bash
npm run install:local
```
