# Embraced by Love Style

> [!IMPORTANT]
> **这是一个个人自用项目。** 它只为作者本人保存、调用和持续校准个人文风；仓库与 npm 包公开，仅用于个人版本管理、跨设备安装和迭代，不以通用写作模板为目标。

一个从作者个人作品中持续蒸馏的中文文风 Skill，适用于 Codex 中的散文、随笔、书信、短诗、成长叙事、年终回望、续写、润色与审稿。

它追求私人化的感知和意识流式联想：把散落、矛盾的情感汇聚到笔尖，再顺着当下的记忆与呼吸，流畅地“挤”成文字。

它不是标志句式、固定意象或篇章模板的集合，也不靠机械拆散排比、删除金句、缩短解释来制造所谓“人味”。整齐、浓烈、繁复都可以保留，只要它们从当前语境自然长出，仍属于这个具体的人。

### 《又是这个路口，中山路的樟树又抽出新芽》

> 蝉鸣在树冠深处织成金线，将记忆缝进每片摇动的叶影里。
>
> 十字路口的红绿灯换了三次颜色，我仍站在原地数那些飘落的花。原来有些道别不需要挥手，就像当年严厉的批评，温热的期望不需要只言片语。

### 《十年后，我扇出的一巴掌重重地落在了我脸上》

> 也许，十年前，我对他被欺凌时的沉默，像是我在加害他时扇出的一巴掌，而十年后，我们的擦肩而过，是那一巴掌重重的回落在我的脸上。

## 安装或更新

```bash
npx embraced-by-love-style@latest
```

再次执行同一命令即可更新。更新前，安装器会把原目录完整备份到：

```text
~/.codex/skills/.embraced-by-love-style-backups/
```

预览操作或指定其他 Codex skills 目录：

```bash
npx embraced-by-love-style@latest --dry-run
npx embraced-by-love-style@latest --target /path/to/skills
```

## 使用

```text
$embraced-by-love-style 根据这些真实素材，写一篇中度文风的成长散文。
```

```text
$embraced-by-love-style 保留事实和我的口吻，让情绪自然流动；只修突兀和失真，不要机械拆掉排比、金句或解释。
```

默认采用中度文风。可以明确要求轻度、中度或高度浓度。

### 文风原则

Skill 学习的是情感怎样聚拢、记忆怎样互相触发、念头怎样推着下一句话出现，不复制作者旧作的固定开头、复沓句、转折句、结尾句或高频意象。新的作品应当像同一个人在新的处境里继续表达，而不是旧作换了一组名词。

### 素材规则

Skill 只采用当前提示词中明确提供的素材，不会主动扫描当前工作区寻找“真实经历”。提示词有真实素材时据此写作；没有素材时直接原创，不追问、不放占位符，也不会把虚构内容声称为作者亲历。

## 本地迭代

Skill 源文件位于 `skill/embraced-by-love-style/`。修改后依次运行：

```bash
npm test
npm run install:local
```
